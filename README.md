# ⚔️ RL Mage Battle

Проект по Reinforcement Learning (RL)

Агент обучается сражаться в пошаговой битве магов с помощью алгоритма Q-Learning

---

# 📌 Описание проекта

В игре участвуют 2 мага:

- RL-агент
- противник

Во время боя агент должен принимать решения:

- атаковать
- лечиться
- ставить щит
- восстанавливать ману

Цель агента:
победить противника и максимизировать награду

---

# 🧠 Используемые технологии

- Python
- Q-Learning
- Reinforcement Learning
- Tkinter
- Matplotlib
- Streamlit

---

# 🎮 Возможности проекта

## Обучение агента
Агент обучается через тысячи боев

## Визуализация боя
Пошаговая визуальная демонстрация битвы магов

## Графики обучения
Отображение:
- win rate
- средней награды
- прогресса обучения

## Web Dashboard
Интерфейс на Streamlit:
- просмотр графиков
- GIF боя
- запуск обучения
- запуск демонстрации
